# SU7 Ultra / Performance Film

独立概念网站，非小米官方网站。影像来自用户提供的 `10月29日.mov`。

直接打开 `index.html` 即可使用，不需要安装依赖或运行构建。
部署时保留 `index.html`、`styles.css`、`story.js`、`app.js` 和整个 `assets/` 目录。

## 交互

- 从序幕开始，十次独立向下滚动对应十段影像，播放期间不排队或跳章。
- 向上滚动返回上一章，使用压黑过渡，不将原音轨倒放。
- 支持箭头按钮、章节导航、方向键和手机上下滑动。
- 声音默认关闭，可主动开启；保留原片音轨并随每段暂停。
- 原片按钮独立连续播放完整视频。
- 检测到减少动态效果偏好时，直接切换到下一章定格画面。

## 配置

所有停靠时间、章节文字和输入参数集中在 `story.js`。
`STATIONS` 包含序幕和十个章节。`hold` 为实际视频时间，单位秒。

源素材为 2348 x 1080、30fps、57 秒。网页视频仅裁去外围录屏界面，
画面区域为 `crop=1920:788:214:148`，H.264 / AAC，原音轨保留。
采用原生视频分段播放以保持声画同步；HTTP 部署时全量加载后开放交互，
直接打开本地 HTML 时由浏览器读取相邻视频文件。
不做虚构的 360 度旋转或车型参数。

