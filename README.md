# SU7 Ultra / Performance Film

独立概念网站，非小米官方网站。影像来自用户提供的 `10月29日.mov`。

## 在线访问

公开地址：https://hihi-hi521.github.io/su7-ultra-film/

托管在 GitHub Pages，发布源为 `main` 分支根目录。推送更新后自动重新发布。
本次没有开通付费托管或购买域名。中国境内不同网络的访问情况需要分别实测。

直接打开 `index.html` 即可使用，不需要安装依赖或运行构建。
部署时保留 `index.html`、`styles.css`、`story.js`、`app.js` 和整个 `assets/` 目录。

## 交互

- 从序幕开始，十次独立向下滚动对应十段影像，每段约 1.4–2.8 秒。
- 连续操作可结束当前段并进入下一段，不积压输入。向上或跳章直接显示定格图。
- 支持箭头按钮、章节导航、方向键和手机上下滑动。
- 背景音乐默认关闭，主动开启后独立循环，不随章节暂停或重置。
- 音轨来自原片混音，仍包含其中的音效，并非纯音乐分离。
- 原片按钮按需加载高画质完整视频。观看时暂停背景音乐，关闭后恢复。
- 页面隐藏时暂停媒体，返回后恢复已开启的背景音乐。
- 检测到减少动态效果偏好时，直接切换到下一章定格画面。

## 配置

所有停靠时间、章节文字和输入参数集中在 `story.js`。
`STATIONS` 包含序幕和十个章节。`hold` 为源视频时间，`duration` 为加速后
短片的实际时长，单位均为秒。`clip` 和 `still` 指向各章节的短片和定格图。
`SETTINGS.mediaWait` 控制缓冲回退的等待上限，默认 650 毫秒。

源素材为 2348 x 1080、30fps、57 秒。网页视频仅裁去外围录屏界面，
画面区域为 `crop=1920:788:214:148`。交互使用十个独立 H.264 静音短片：
1280 x 526、24fps、CRF27、MP4 fast-start，总计 2,129,685 字节，
较之前的 21,948,773 字节减少 90.3%；首段只有 109,941 字节。
章节定格图共 235,024 字节，独立 AAC 循环音轨为 453,078 字节。

首屏只需静态海报和脚本即可操作，不等待媒体下载。两个原生视频槽位按需加载，
仅预取下一段。缓冲超过 650 毫秒或播放失败时进入对应定格图，导航始终可用。
高画质原片与背景音乐都不会在首屏请求，分别在点击原片或开启声音后加载。
图标也改为本地 Lucide 精简包（约 5 KB），无外部 CDN 依赖。
不做虚构的 360 度旋转或车型参数。


```sh
PORT=4174 MEDIA_DELAY_MS=15000 node tests/preview-server.cjs
```
